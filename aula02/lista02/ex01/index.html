Ensino de pensamento computacional de forma desplugada

Trabalho no desenvolvimento de um projeto que visa a criação de uma ferramenta para o ensino de programação de forma desplugada. Para isso, foi desenvolvido um carrinho controlado por Arduino via Bluetooth, o qual também pode ser acionado por um aplicativo Android. Esta ideia surgiu da busca por uma forma de ensinar conceitos de programação para crianças de maneira lúdica, interativa e sem o uso de telas. Para isso, a estrutura escolhida foi a programação em blocos, na qual serão usados blocos impressos em 3D com códigos de barras. Eles poderão ser montados de forma livre pelo aluno e, após isso, será feita a leitura dos códigos. Um software desenvolvido para Raspberry Pi 4 fará a validação, interpretação e enviará os comandos para que o carrinho se movimente de acordo com a sequência montada pelo aluno.
