Etapas do projeto

Itens necessario para o projeto

  • Carrinho controlado pro arduino e comandado por Bluetooth
  • Interpretaor e controlador desenvovido em C++ e rodando em uma Raspberry4
  • Blocos coloridos impressos em 3D com etiqueca com codigo de barras

Sequencia para o desenvolvimetno

  1. Desenvolver carrinho com funcionalidades básicas
  2. Desenvolver interpretador com funcionalidades de movimentação do carrinho
  3. Desenvolver blocos com movimentações básicas
  4. Incluir estrutura de repetição PARA no interpretador
  5. Desenvolver blocos com a estrutura PARA
  6. Incluir estrutura SE no interpretador
  7. Desenvolver blocos com a estrutura SE
  8. Incluir estrutura ENQUANTO no interpretador
  9. Desenvolver blocos com a estrutura ENQUANTO
  10. Incluir luzes no carrinho, utilizando simulação de threads
  11. Incluir comandos de luzes no interpretador
  12. Desenvolver blocos com os comandos de luzes
  13. Implementar sensores anticolisão no carrinho, utilizando sensores de distância ultrassônicos e simulação de threads
  14. Alterar esquema de leitura dos blocos para que seja feito por uma camera e utilizando IA para fazer a leitura dos codigos de barras e definir a sequencia

Materiais usados e sua função

Arduino
Usado para controlar o carrinho e fazer a conexão bluetoth usando modulo HC05
Leitor de codigo de barras sem fio
Usado para fazer a leitura dos codigos de barras
Raspberry4
Usado para rodar a interpretação dos blocos montados e enviar os comandos para o carrinho
